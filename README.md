# 🛒 Superstore Sales Analysis Dashboard

An interactive sales analytics dashboard built with Python, Streamlit & Plotly.

## ✨ Features
- Total Sales, Profit & Orders - Real-time KPIs
- Sales by Category, Region & Segment
- Monthly Sales Trend Analysis
- Top 10 Products & Customers
- Interactive Filters - Region, Category, Year

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## 🚀 How to Run
pip install streamlit pandas plotly
streamlit run dashboard.py
